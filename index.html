Clean Deploy Checklist

Do not merge this over the old app. Delete the old repo files/folders first, then upload this clean package. The old files are what kept bleeding into each other.
  1. In GitHub, delete old root files and the old netlify/functions folder.
  2. Upload this package exactly as-is.
  3. Confirm root has index.html, netlify.toml, and package.json.
  4. Confirm netlify/functions contains only the new ohmboy-*.js functions and _lib/store.js.
  5. Netlify deploy settings: publish directory ., functions directory netlify/functions.
  6. After redeploy, open /.netlify/functions/ohmboy-health.
  7. Do not proceed until the response says "backend": "netlify-blobs" and "roundTrip": { "ok": true }.
